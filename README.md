# CodeAlpha Python Programming Internship

This repository contains my completed tasks for the CodeAlpha Python Programming internship.

## Tasks
1. **Hangman Game** (`hangman.py`) - text based game with a word list, hints, drawing, score and play again option.
2. **Task Automation** (`email_extractor.py`) - reads `input.txt`, extracts email addresses using regex, removes duplicates, prints a report and saves them in `emails.txt`.
3. **Basic Chatbot** (`chatbot.py`) - rule based chatbot with keyword matching, name memory, time/date, jokes and a saved chat log.

## How to run
```
python hangman.py
python email_extractor.py
python chatbot.py
```

## Concepts used
random, while loops, if/elif/else, strings, lists, dictionaries, functions, file handling, regular expressions (re), datetime, try/except.
